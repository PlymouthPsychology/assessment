## This is the 2025 version of the Dissertation marking system, updated to reflect the move to Limesurvey.

**Dissertation.Rmd** processes everything and produces a Word file Dissertations.docx, formatted using the word-reference.docx file
**ChopperUpper.R** produces files for each marker to send back to them at the end of the process.

Before using, some data files need to be added to the empty folders:

- allocations: save the UG and PG marking allocation tabs as separate files
- enrolments: the enrolment reports from S4 for each module (605, 707,722, 723,724) Save Details only, it does not matter whether .xlsx or .csv
- marksheets: the empty DLE Gradebooks from each project submission point
- surveydata: the Responses expported from psysurvey (use Question Code only for headers)

- personal: this folder is populated by ChopperUpper.R to send markers their data back at the end.
